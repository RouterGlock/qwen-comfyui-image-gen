# MURBEREC® logo: final files

The "synapse M": an angular M whose strokes meet at a cyan node with three
branches, a synapse firing. Chosen from Qwen-Image concept
`1-synapse-monogram-4`, then redrawn by hand as clean geometry. The
wordmark is Manrope ExtraBold, converted to outlines so no font is needed.

| File | Use |
|---|---|
| `murberec-logo-on-light.svg` | Full logo on white / off-white backgrounds |
| `murberec-logo-on-dark.svg` | Full logo on dark backgrounds |
| `murberec-logo.svg` | Full logo; ink follows CSS `currentColor` |
| `murberec-mark.svg` | The M alone (ink = `currentColor`); app icons, avatars |
| `favicon.svg` | Browser tab icon |

Colours: ink `#09090B` (or `#FAF9F5` on dark), cyan `#23D2E2`.
Don't place the logo on a cyan background: the node and ® disappear.
Keep clear space around it of at least the height of the node.
